# Hello C#
## Simple survival guide (Documentation) to my journey learning C# syntax and OOP theory.
###### By: Manuel Ortega

This is my first C# code, it's the basic and superior "Hello World" 
```csharp
class Program {
    static void Main() {
        Console.Write("Hello World and hello you to C# ;)");
    }
}
```
Alright, let's break down the code step by step.  
Line 1 ``class Program`` is a class declaration. Basically, the code is telling the compiler:  
'Hey, I need you to create a blueprint called a class, and name it Program"

Line  2 ``void Main()`` is a method declaration. The code is telling the compiler:   
'Hey, I need you to create a method called Main 

Line 3 ``Console.Write("Hello World and hello you to C# ;)")`` is a method call. The code is telling the compiler:   
'Hey, I need you to call the method Write from the Console class, and pass it the string "Hello World and hello you to C# ;)" so now go to print this on the display when the program runs.!
